# 投資信託ポートフォリオ最適化アプリ v3.6.0

## 📊 コアサテライト戦略 + 構成銘柄詳細分析 + CVXPY凸最適化エンジン

**バージョン**: 3.6.0  
**リリース日**: 2026年3月30日  
**ステータス**: ✅ Production Ready

---

## 🎯 概要

投資信託のポートフォリオ最適化を自動化する高度なWebアプリケーション。

**v2.0の新機能**: 構成銘柄の詳細分析タブを追加し、各ファンドの全期間データでの詳細分析が可能になりました。

---

## ✨ 主な機能

### コア機能（v1.x）

1. **自動ファンドスクリーニング**
   - 150本以上のファンドから最適な20本を自動選定
   - 多段階フィルタリング（シャープレシオ、DD、相関）

2. **5段階リスクプロファイル最適化**
   - 積極型、やや積極型、バランス型、やや保守型、保守型
   - コア比率を自動調整（20-95%）

3. **詳細分析機能**
   - パフォーマンス分析（累積リターン、年次リターン）
   - 構成分析（パイチャート、トリーマップ）
   - リスク分析（ドローダウン、VaR/CVaR）
   - 相関分析（マトリックス、ローリング相関）
   - モンテカルロシミュレーション

4. **可視化**
   - インタラクティブなPlotlyチャート
   - ベンチマーク比較
   - リスク・リターンマップ

5. **エクスポート機能**
   - Excel形式での結果出力

### 新機能（v2.0） 🆕

6. **構成銘柄詳細分析タブ**
   - 各構成ファンドの個別詳細分析
   - オリジナルデータ全期間での評価
   - 多期間リターン表示（1年/3年/5年/10年/設定来）
   - ベンチマーク比較強化
   - リスク指標（シャープレシオ、最大DD）
   - パフォーマンス推移グラフ（指数化）
   - 統計サマリー


## 📊 データ形式

### 入力データ

**Excelファイル (.xlsx)**

| Date       | J01 Fund A | J02 Fund B | ... | 世界株 |
|------------|-----------|-----------|-----|-------|
| 2022-01-31 | 100.0     | 105.2     | ... | 1000.5|
| 2022-02-28 | 101.5     | 103.8     | ... | 1020.3|
| ...        | ...       | ...       | ... | ...   |

**要件**:
- Date列: 月次の日付（datetime形式）
- ファンド列: 各ファンドの基準価格（数値）
- 推奨データ期間: 3年以上（36ヶ月以上）
- 推奨ファンド数: 50本以上

### 基本的なワークフロー



## 🔧 技術仕様

### 使用技術

- **フレームワーク**: Streamlit
- **データ処理**: Pandas, NumPy
- **最適化**: SciPy (SLSQP法)
- **可視化**: Plotly
- **ファイル処理**: OpenPyXL

### 最適化手法

- 制約付き非線形最適化
- 目的関数: シャープレシオ最大化、ボラティリティ最小化など
- 制約: コア比率、個別上限、合計=100%

### 評価指標

- シャープレシオ、ソルティノレシオ
- カルマー比率
- 最大ドローダウン
- VaR/CVaR
- ローリング統計

## 📈 v2.0の改善点

### 新機能

| 機能 | 説明 |
|-----|------|
| 構成銘柄分析タブ | 各ファンドの詳細分析を個別に表示 |
| 全期間データ分析 | オリジナルデータ全期間を使用（分析期間に限定されない） |
| 多期間リターン表示 | 1年/3年/5年/10年/設定来のリターンを一覧表示 |
| ベンチマーク比較強化 | 表形式で明確に比較、色分け表示 |
| リスク指標表示 | シャープレシオ、最大ドローダウンを明示 |
| パフォーマンスグラフ | 全期間の指数化チャート |
| 統計サマリー | 設定来リターン、年率リターン、ボラティリティ、期間を表示 |

### 利点

1. **長期視点での評価**: 分析期間に限定されず、ファンドの真の実力を評価
2. **多角的分析**: 複数期間のリターンを比較し、トレンドを把握
3. **明確な比較**: ベンチマークとの差が一目瞭然
4. **リスク可視化**: シャープレシオとドローダウンで総合評価
5. **使いやすさ**: タブ形式で各ファンドを整理

### 3. 顧客への説明資料作成
- 各ファンドの詳細データをエビデンスとして活用
- 視覚的なグラフで分かりやすく説明
- Excelエクスポートでレポート作成

### 4. リスク管理
- 最大ドローダウンから下落耐性を評価
- ボラティリティでリスク水準を把握
- シャープレシオで効率性を測定

## 📝 注意事項

### データ要件
- 各ファンドに最低12ヶ月以上のデータが必要
- 構成銘柄分析は比重0.5%以上のファンドのみ表示

### パフォーマンス
- 構成銘柄が多い場合（10本以上）、タブ切替に若干時間がかかる可能性
- 大量データの場合は分析期間を調整することを推奨

### ブラウザ推奨
- Google Chrome（推奨）
- Firefox
- Edge
