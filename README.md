# 投資信託ポートフォリオ最適化アプリ v3.6.0

**バージョン**: 3.6.0  
**リリース日**: 2026年3月30日  
**ステータス**: ✅ Production Ready

コアサテライト戦略に基づく投資信託ポートフォリオの自動最適化アプリケーション。
150本以上のファンドから相関バケット別スクリーニングで最適な20本を選定し、
7種類の目的関数（CVXPY凸最適化 + SLSQPフォールバック）で
5段階リスクプロファイル＋リスクパリティ＋テールリスク最小型の計7ポートフォリオを同時生成する。

---

## クイックスタート

```bash
pip install -r requirements.txt
streamlit run portfolio_app.py
```

Excelファイル（Date列 + 各ファンドの月次基準価格）をアップロードし、
分析期間・コアファンド・ベンチマークを選択して「分析実行」をクリック。
詳細は `QUICKSTART.md` を参照。

## アーキテクチャ

5モジュール構成のDAG（有向非巡回グラフ）。循環依存なし。

```
portfolio_app.py（エントリーポイント, 約1,850行）
  ├→ portfolio_utils.py   計算層: 最適化・スクリーニング（約2,720行）
  ├→ portfolio_data.py    データ層: Excel読込・概観テーブル（約440行）
  ├→ portfolio_charts.py  描画層: Plotlyチャート・タブ描画（約2,050行）
  └→ portfolio_report.py  レポート層: サマリーパネル・Excel出力（約1,370行）
```

portfolio_utils.pyとportfolio_data.pyは外部依存なし（leaf）。
portfolio_charts.pyはutils内の`calculate_fund_metrics`のみを参照。
portfolio_report.pyはchartsの`donut_svg`/`badge`とutilsの`PortfolioAnalyzer`を参照する。

CVXPYとscikit-learnはオプショナル依存として`try/except`でガードされており、
未インストール時はSLSQP（SciPy）とサンプル共分散行列にフォールバックする。

## 最適化エンジン

### CVXPY凸最適化（優先パス）

CVXPYが利用可能な場合、以下の目的関数は凸問題として厳密に解かれる。
マルチスタートや射影関数が不要になり、グローバル最適解と制約充足を同時に保証する。

| 目的関数 | 定式化 | 解法 | 対象プロファイル |
|---------|--------|------|------------|
| volatility | QP: min wᵀΣw | CLARABEL | 保守型 |
| max_cagr | QP: max μᵀw − ½wᵀΣw | CLARABEL | 積極型 |
| sharpe | SOCP: Cornuejols-Tütüncü同次化変換 | CLARABEL | やや積極型, バランス型 |
| risk_adjusted | SOCP: max μᵀw − λ‖Lᵀw‖ (λ=1.0) | CLARABEL | やや保守型 |
| return | SOCP: max μᵀw − λ‖Lᵀw‖ (λ=0.1) | CLARABEL | —（λパラメトリック化） |
| min_cvar | LP: Rockafellar-Uryasev定式化 | CLARABEL | テールリスク最小型 |

Sharpe SOCPは分数計画 max (μ−rf)ᵀw/σ(w) を変数変換 y=κw, κ=1/σ(w) で
標準SOCPに帰着させ、SLSQPのローカル解依存を完全に解消する。
returnとrisk_adjustedは同一SOCP構造のλパラメトリック化であり、コード重複はない。

### SLSQPフォールバック

CVXPYが未インストールまたは失敗した場合、SciPy SLSQP法に自動フォールバックする。
解析的勾配（Sharpe/max_cagr/volatility/min_cvar）を提供し、
4点マルチスタート（均等配分 + コア上限寄り + Dirichletランダム2点）で
ローカル解リスクを緩和する。

### リスクパリティ：ハイブリッド2段階方式

リスクパリティは非凸問題のため、Spinu (2013) 凸定式化で高品質な初期点を取得し、
SLSQPマルチスタートのDirichlet点1つをSpinu解で置換する。
RC二乗偏差の非凸目的関数をSLSQPで直接最小化し、
box constraints下でもRC均等性（CV≈5%）を維持する。

### 二段階最適化

全目的関数で共通の二段階フレームワークを採用する。
一段目でmin_individual=0（下限なし）のグローバル最適解を求めてアクティブセットを確定し、
二段目でアクティブセット固定＋min_individual制約を適用して再最適化する。
下限可行性違反（core_min + (n−1)×min_individual > 1.0）は自動検出・自動調整される。

### 制約保証

SLSQPパスの射影関数`_project_to_feasible_simplex`は
多段階カスケード（Step4非コア比例配分→Step5再クリップ→Step6スケーリング＋再配分→最終正規化）
でsum=1とbounds内を保証する。
CVXPYパスの`_cvxpy_clip_and_normalize`も同等の2段階delta再配分＋最終正規化を備え、
両パスで同一の制約堅牢性を保証する。

### 効率的フロンティア

CVXPYが利用可能な場合はパラメトリックQP法を使用する。
`cp.Parameter(λ)`で問題構造を1回だけ構築し、λ値の更新＋`warm_start=True`で
高速に再解する。フロンティア表示にはサンプル共分散を使用し、
散布図のX軸（ポートフォリオボラティリティ）と定義を統一する。

## ファンドスクリーニング（v3.1バケット方式）

コアファンドとの相関係数で候補ファンドを5バケットに分類し、
バケット固有のスコア式（最大11指標の重み付き合計）で評価・選定する。

| バケット | 相関範囲 | 役割 | 重視指標 |
|---------|---------|------|---------|
| マイナス相関 | −1.0〜0.0 | ヘッジ役 | ソルティノ, 最大DD, 下落相関, Omega |
| 低相関 | 0.0〜0.25 | 分散役 | ソルティノ, 最大DD, Omega, GL比率 |
| 中低相関 | 0.25〜0.50 | バランス役 | シャープ, ソルティノ, Omega, GL比率 |
| 中高相関 | 0.50〜0.75 | 収益補完役 | シャープ, Martin, リターン, カルマー |
| 高相関 | 0.75〜1.01 | リターン牽引役 | リターン, カルマー, Martin, GL比率 |

スコアリングにはランク正規化（パーセンタイル変換）を使用し、
外れ値（ソルティノ999.99等）によるスコア圧縮を防止する。
マイナス相関・低相関・中低相関バケットでは相関距離＋ウォード法クラスタリングで
同一戦略への集中を防止し、真の多様性を確保する。

事前フィルターはキャッシュファンド除外（年率ボラティリティ < 3%）のみ。
DDフィルターはv3.1で廃止済み（バケットスコアに組み込み済みのため二重管理を解消）。

条件付き下落相関（コアが下落した月のみの相関）と相関安定性（12ヶ月ローリング相関のσ）を
スクリーニング指標に組み込み、「平常時は低相関だが危機時に急上昇する」ファンドを識別する。

## 評価指標（14指標）

PortfolioAnalyzer、FundScreener、calculate_fund_metricsの3箇所で計算定義を完全統一。

| 指標 | 定義 | 備考 |
|-----|------|------|
| 年率リターン（CAGR） | (1+cum)^(12/T) − 1 | 表示用。カルマー・Martin比率の分子 |
| 年率期待リターン | mean(r) × 12 | 最適化用。シャープ・ソルティノの分子 |
| 年率ボラティリティ | √(wᵀΣw) | 共分散ベース。NaN時はstd(ddof=1)×√12にフォールバック |
| シャープレシオ | (μ_arith − rf) / σ | vol < 1e-8 はゼロガード |
| ソルティノレシオ | (μ_arith − rf) / DD(τ) | Sortino & van der Meer (1991)。全期間T個で平均 |
| 最大ドローダウン | min{(cum_t − max) / max} | 先頭1.0付加で期初損失を捕捉 |
| カルマー比率 | CAGR / \|最大DD\| | 負値保持（[-999.99, 999.99]） |
| 月次VaR (95%) | sorted[k−1], k=floor(T×0.05) | index-based離散推定量 |
| 月次CVaR (95%) | mean(sorted[:k]) | ワーストk本の平均 |
| 月次勝率 | count(r>0) / T | — |
| Omega比率 | Σmax(r−τ,0) / Σmax(τ−r,0) | τ=0。非正規分布対応 |
| Ulcer指数 | √(mean(DD²)) | 深く長いDDほど大きい |
| Martin比率 | CAGR / Ulcer指数 | カルマーのUlcer版 |
| GL比率 | avg_gain / \|avg_loss\| | 売りオプション系の識別に有効 |

## 共分散推定

サイドバーでLedoit-Wolf収縮推定量（デフォルト）とサンプル共分散行列を切替可能。

Ledoit-Wolfはノイズを統計的に圧縮し、36ヶ月などの短期データでも最適化の安定性を維持する。
収縮係数はUIに表示される。scikit-learn未インストール時やデータにNaN/Infが含まれる場合は
サンプル共分散に自動フォールバックする。

効率的フロンティアと散布図のX軸はサンプル共分散で統一し、
最適化内部のみLedoit-Wolfを使用する設計。
Cholesky因子はPortfolioAnalyzer初期化時に事前計算（微小対角摂動で正定値性を保証）し、
SOCP定式化で直接使用する。

## モンテカルロシミュレーション

対数正規モデルを採用。月次パラメータは以下のとおり計算する。

```
μ_log = ln(1 + E[r_arith]) − σ²/2
σ_log ≈ std(r_arith, ddof=1)
```

ドリフト項に算術平均リターンを使用（v2.0.1でCAGRから修正済み）。
σの近似誤差は月次ボラ2−5%で0.4%以下。
シード固定（seed=42）により再現性のあるレポート出力に対応。
パーセンタイル帯（5/25/50/75/95%）とパス100本を同時表示する。

## UI機能

### 顧客向け表示 / 担当者モード

ボタン一つで切替。顧客向け表示はリッチHTMLカードで
リターン・リスク・コア比率を視覚的に提示する。
担当者モードは6タブの全詳細指標にアクセス可能。

### 全ファンド概観テーブル

マルチピリオドリターン（1年/3年/5年/10年/設定来CAGR）、
リスク指標（ボラティリティ/最大DD/シャープレシオ/月次勝率）、
コア相関（設定来/分析期間/ローリング安定性σ）を全ファンド横並びで表示する。
サイドバーのチェックボックスで3タブ（パフォーマンス/リスク/相関）を切替。

### 構成銘柄詳細分析（Tab6）

ウェイト0.5%以上の構成ファンドについて全期間データでの個別詳細分析を提供する。
多期間リターン表、ベンチマーク比較表、リスク指標（Omega/Ulcer/Martin/GL含む）、
全期間パフォーマンス推移グラフをexpander形式で表示。

### 構成ファンド個別分析（Drill Section）

プロファイルタブの切り替えに連動し、ウェイト1%以上のファンドを
タブ形式で個別表示する。コアファンドとの相関、分析期間内のパフォーマンス、
リスク指標をファンド単位で確認可能。

### Excelエクスポート

1クリックでダウンロード完了。ポートフォリオ比較シート、統合ファンド構成シート、
各プロファイル個別シート（構成ファンド＋ポートフォリオ合計行）、
ファンド統計シートを含む。全列floatで数値ソート・集計に対応。

## データ要件

| 項目 | 要件 |
|-----|------|
| ファイル形式 | .xlsx（Excel） |
| 必須列 | Date（月次日付）+ 各ファンドの基準価格（数値） |
| 推奨期間 | 3年以上（36ヶ月以上） |
| 推奨ファンド数 | 50本以上 |
| 欠損許容 | コア期間内欠損率0%のファンドのみ分析対象 |
| 通貨列 | USD-JPY等は自動除外（CURRENCY_KEYWORDSで一元管理） |

分析期間はコアファンドのデータ有効期間でアンカーされる。
コアファンドが選択期間内にデータ欠損を持つ場合は警告が表示され、
実効分析期間が通知される。
